# Python API Data Pipeline

## Overview

A Python application that retrieves data from external REST APIs,
processes JSON responses, validates records, and stores information
in an SQLite database.

## Objectives

- Integrate with external REST APIs.
- Process and validate JSON data.
- Detect duplicate records.
- Store structured data using SQLite.
- Handle API errors and failed requests.
- Implement automated tests.

## Technologies

- Python
- REST APIs
- JSON
- SQLite
- Git
- Pytest

## Project Structure

- src/: Application source code
- tests/: Automated tests
- data/: Local database and sample data
- docs/: Technical documentation
